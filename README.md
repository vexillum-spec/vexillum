# vexillum (reserved)

This repository holds the `vexillum` package on [npm](https://www.npmjs.com/package/vexillum)
and [PyPI](https://pypi.org/project/vexillum/), reserved for the **Vexillum**
standard: agent pipelines that live in the repository.

It will grow into the Vexillum CLI (`vex`) — the headless runner and tooling
for `.vexillum/` pipelines. Until then the packages are intentionally minimal
and do nothing beyond pointing here.

- **Specification:** [vexillum-spec/spec](https://github.com/vexillum-spec/spec)
- **Website:** [vexillum.io](https://vexillum.io)
- **Reference implementation:** [StreamKanban](https://github.com/Forgebotica/StreamKanban)

| Folder | Registry | Package |
|---|---|---|
| `npm/` | npm | `vexillum` (binary: `vex`) |
| `pypi/` | PyPI | `vexillum` |
