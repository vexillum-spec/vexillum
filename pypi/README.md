# vexillum

Reserved for the **Vexillum** standard: agent pipelines that live in the
repository, defined in a `.vexillum/` directory and inherited by everyone who
clones the repo.

This package will grow into Vexillum tooling for Python. Until then it is a
pointer:

- **Specification:** https://github.com/vexillum-spec/spec
- **Website:** https://vexillum.io
- **Reference implementation:** https://github.com/Forgebotica/StreamKanban
